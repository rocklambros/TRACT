# Lint and type-check toolchain for the CI `lint` job.
#
# Why this file exists: the lint job used to run `pip install ruff mypy` with
# no version constraint, so the gate's definition changed under the repo
# without a commit. Main's 2026-07-01 run installed ruff 0.15.20 and its
# 2026-07-11 run installed 0.15.21, while requirements.txt declared 0.11.12.
# CI was enforcing a linter the project never agreed to. Pinned per QC.1
# (NIST SP 800-218).
#
# Kept separate from requirements.txt so the lint job stays fast: it does not
# need torch, wandb or hdbscan, and hdbscan compiles from source.
#
# Everything below that also appears in requirements.txt is listed WITHOUT a
# version on purpose. The -c line pins it to whatever requirements.txt says,
# which makes that file the single source of truth and means a dependabot
# bump there needs no follow-up edit here. Duplicating the versions instead
# made every bump a hard pip conflict until someone hand-synced both files;
# PR #7 (jsonschema 4.23.0 -> 4.26.0) is what demonstrated that.
-c requirements.txt

# Linters. Versions come from requirements.txt via the constraint above, so a
# developer running `ruff check` locally sees exactly what CI sees.
ruff
mypy

# Runtime deps mypy imports during --strict analysis. numpy and
# huggingface_hub ship py.typed, so installing them buys real type checking
# instead of an ignore_missing_imports blanket. The heavy ML stack stays out
# and is silenced by the mypy overrides in pyproject.toml.
pydantic
anthropic
jsonschema
pyyaml
beautifulsoup4
lxml
requests
numpy
huggingface_hub

# Type stubs. Not runtime dependencies and absent from requirements.txt, so
# these are the only entries that carry their own pin.
types-beautifulsoup4==4.12.0.20250516
# The CAPEC and CWE parsers use defusedxml, and CLAUDE.md documents the
# type-check command as `mypy parsers/ scripts/ --strict`. Without these
# stubs that command fails while CI, which checks only tract/ and
# scripts/phase1a/, stays green.
types-defusedxml==0.7.0.20260504
types-jsonschema==4.26.0.20260518
types-PyYAML==6.0.12.20260724
types-requests==2.33.0.20260712
