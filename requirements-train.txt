# Pinned TRAINING and EVALUATION stack. Not the serving stack.
#
# WHY THIS IS SEPARATE FROM requirements-ml.txt
# requirements-ml.txt is the *serving* pin: the environment validated to load
# published revision 2d20955, pass TRACTPredictor's health check and return
# sensible hubs. Moving it to the versions below would change what `tract
# assign` users get, and by that file's own argument a change in the encoder
# stack changes embeddings and therefore the confidences already published in
# the crosswalk dataset. Training needs a newer stack than serving does; those
# are two different questions and now two different files.
#
# WHERE THESE VERSIONS COME FROM
# Selected 2026-08-13 and audited with pip-audit. torch 2.4.1 + transformers
# 4.45.1 carried 51 findings; torch 2.8.0 + 4.49.0 carried 31; this stack
# carries 5. It clears every torch finding, including PYSEC-2025-41 (RCE via
# torch.load) and PYSEC-2026-2286, which are the two that map onto what TRACT
# does: download an artifact and load it. The 5 residual findings are all
# transformers, all in X-CLIP, MobileViT, MaskFormer and Trax checkpoint
# conversion paths; grep of tract/ and scripts/ returns no reference to any.
#
# WHY NOT transformers 5.x, WHICH HAS ZERO FINDINGS
# transformers 5.x requires huggingface-hub>=1.5.0, while TRACT declares
# huggingface_hub>=0.24,<1 as a core dependency. The 4->5 boundary is exactly
# the hf_hub 0.x->1.x boundary, and crossing it forces a migration of six call
# sites including tract/model_resolver.py, the sha256-verified download path
# behind `tract assign`. That is not a change to make in the same commit as a
# metrics re-derivation.
#
# CUDA BOUNDARY
# torch's cu12->cu13 split falls between 2.10.0 (last cu12) and 2.11.0. torch
# 2.13.0 needs CUDA 13, so the old
# runpod/pytorch:2.4.0-py3.11-cuda12.4.1-devel-ubuntu22.04 tag cannot run it.
# The digest pinned in scripts/phase1b/runpod_parallel.py is the CUDA 13.0
# image. The documented fallback is the CUDA 12.8.1 image with torch==2.10.0,
# which costs two local-only torch findings.
#
# Install:  pip install -r requirements.txt -r requirements-train.txt
-c requirements.txt
